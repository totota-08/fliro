# Fliro
小規模チーム向けのプロジェクト管理ツールです（旧称 Teamie）。

## Git ブランチ戦略
- ベースブランチ: `develop`
- プレフィックス: 新機能 `feature/`、バグ修正 `fix/`、環境・設定 `chore/`、緊急対応 `hotfix/`
- フロー: `git checkout develop` → `git pull` → `git checkout -b <branch_name>`
- プルリクエストは `develop` 向けに作成（hotfix は `main` と `develop` の両方）

## UI/UX ガイド（要約）
- 情報階層: プロジェクト → タブ（チャット/ダッシュボード/タスク/メンバー/設定/タイムライン/履歴）→ セクション
- 余白: 16px/20px/24px を基本に統一
- カラー: デザイントークンを使用し、ハードコード禁止
- コンポーネント配置: タイトルは左上、主操作は右上に配置
- レスポンシブ・アクセシビリティを常に確認（キーボード操作/ARIA/コントラスト）
