```

│ 進行中 | 完了                                                │
├─────────────────────────────────────────────────────────────┤
│                                                               │

│  │ タスクの詳細な内容がずらずらと書いてあって、        │    │
│  │ 情報が多すぎて何が重要かわかりません...              │    │
```

**問題点:**

- 説明文が長すぎて、タイトルより目立ってしまう

- 50件のタスクが一度に表示され、重い
- スマホで操作しにくい（ボタンが小さい）

## 🎨 デザインシステムの統一

### Before（バラバラ）

```
ページA:                    ページB:                    ページC:
┌────────┐                 ┌────────┐                 ┌────────┐
│[ボタン]│  角丸12px       │[ボタン]│  角丸8px        │[ボタン]│  角丸0px
└────────┘  影: 強          └────────┘  影: 弱          └────────┘  影: なし
色: #4f7c82                色: #5a8a90                色: #3f6c72
```

→ ページごとに微妙に違うデザイン（統一感がない）

---

### After（完全統一）✨

```
すべてのページで同じ:
┌────────────┐
│  [ボタン]  │  角丸: var(--ui-radius-md) = 12px
└────────────┘  影: var(--ui-shadow-btn-primary)
                色: var(--ui-brand-600) = #4f7c82

すべてのバッジが同じ:
[成功] → 緑の背景（var(--ui-success-light)）
[警告] → 黄色の背景（var(--ui-warning-light)）
[危険] → 赤い背景（var(--ui-danger-light)）
```

## ✨ まとめ

### 視覚的な改善

1. **情報の優先度が明確**
   - タイトル > 期限 > 説明 の順に目立つ
   - 重要な情報が色とサイズで強調される

2. **統一されたデザイン**
   - すべてのページで同じボタン・バッジ・モーダル
   - Deep Greenカラーパレットが統一

3. **モバイルフレンドリー**
   - タッチターゲットが大きく、タップしやすい
   - 横スクロールが完全にゼロ
   - 縦並びレイアウトでスマホに最適化

4. **初心者に優しい**
   - 空状態に「次のアクション」が明示
   - オンボーディングヒントで使い方がわかる
   - 「さらに表示」で情報過多を防ぐ
